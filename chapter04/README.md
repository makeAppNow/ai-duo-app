## 기본 4-2. 로컬 서버 만들기: MySQL, Docker, 개발 도구

**파일**

```
jdbc-url: jdbc:mysql://localhost:3306/myapp
username: myapp
password: ********
```

**파일**

```
SELECT * FROM trainees WHERE trainees_id = 1;
INSERT INTO trainees (trainees_name, trainees_gender) VALUES ('김지수', '여');
UPDATE trainees SET trainee_status = 'EXPIRED' WHERE trainees_id = 1;
DELETE FROM trainees WHERE trainees_id = 1;
```

**AI에게** · MySQL 컨테이너 띄우기.

```text
내 맥에 Docker로 MySQL 8.0을 띄워줘. 컨테이너 이름은 myapp-mysql, 포트는 3306. 데이터는 볼륨에 저장해서 컨테이너를 지워도 남게 해줘. 앱 서버가 쓸 데이터베이스(myapp)와 접속 계정도 하나 만들어줘. 비밀번호는 명령에 적지 말고 내가 넣을 자리를 알려줘.
```

**터미널**

```bash
docker run -d --name myapp-mysql -p 3306:3306 -v myapp_mysqldata:/var/lib/mysql -e MYSQL_ROOT_PASSWORD=관리자비밀번호 -e MYSQL_DATABASE=myapp -e MYSQL_USER=myapp -e MYSQL_PASSWORD=비밀번호 mysql:8.0
```

**파일**

```
CREATE USER 'myapp'@'%' IDENTIFIED BY '비밀번호';
GRANT ALL PRIVILEGES ON myapp.* TO 'myapp'@'%';
ALTER USER 'myapp'@'%' IDENTIFIED BY '새비밀번호';
```

**AI에게** · 서버 프로젝트 만들기.

```text
이 앱에 서버를 붙이자. 회원과 수업 데이터를 서버에 저장하고 앱이 서버에서 읽어오게 해줘. 서버 프로젝트는 별도 폴더로 만들고, 언어는 네가 제일 단순한 걸로 골라줘. 데이터베이스는 방금 Docker로 띄운 MySQL을 써. 일단 내 맥에서 돌려보자.
```

**AI에게**

```text
로컬 MySQL(myapp-mysql 컨테이너)에 터미널로 접속하는 명령을 알려줘. 방금 앱에서 등록한 회원이 trainees 표에 들어갔는지 확인하는 SELECT 문도 같이 써줘.
```

**AI에게** · 어디에 걸지 모를 때.

```text
앱에서 회원을 등록하면 서버의 어느 파일 몇 번째 줄을 지나가? 거기에 브레이크포인트를 걸어서 앱이 보낸 값을 보고 싶어. 줄 위치만 알려줘.
```

**AI에게**

```text
서버의 회원 저장 API를 curl로 불러보는 명령을 알려줘. 성공할 때와 일부러 틀렸을 때 답이 어떻게 다른지 보고 싶어.
```

**AI에게**

```text
이 서버에서 시각을 어느 시간대 기준으로 저장하고 보여주는지 정리해줘. 데이터베이스, 서버, 앱이 같은 기준을 쓰는지 확인하고, 그 기준을 규칙서에 한 줄로 적어줘.
```

## 기본 4-4. 운영 서버 만들기: EC2에 서버 올리기

**AI에게** · 운영 서버에 서버 설치하기.

```text
EC2 인스턴스를 하나 만들었어. 주소는 [IP], 키 파일은 [경로]. 여기에 방금 만든 서버를 올리고 실행해줘. 데이터베이스도 같은 컴퓨터에 깔아줘. 비밀번호 같은 값은 코드에 적지 말고 따로 둬.
```

**AI에게**

```text
앱의 서버 주소를 [IP]로 바꿔줘. 그리고 앱에서 회원을 하나 등록해서 서버에 저장되는지 확인해줘.
```

**AI에게** · git과 deploy key.

```text
EC2 인스턴스에 git을 설치하고, 깃허브의 서버 저장소를 받을 수 있게 읽기 전용 deploy key를 만들어줘. 깃허브 화면에서 내가 붙여 넣을 공개 키와 순서를 알려줘.
```

**파일**

```
Host myapp-prod
  HostName 203.0.113.10
  User ec2-user
  IdentityFile ~/.ssh/myapp-prod.pem
```

**AI에게**

```text
서버 코드를 고쳤어. 운영 서버에 접속해서 새 코드 받고, 빌드하고, 돌고 있는 서버 끄고, 새 걸로 켜줘. 로그에 오류 없는지까지 확인해줘.
```

**AI에게** · 배포 전에.

```text
이번 기능에 데이터베이스 표 변경이 있어? 있으면 운영 DB에 실행할 명령문만 따로 뽑아줘. 옛 서버가 새 표 위에서도 문제없이 도는지, 지우거나 이름을 바꾸는 명령이 들어 있는지도 같이 알려줘.
```

**AI에게** · 오류 줄을 붙일 때.

```text
서버 로그에 이런 ERROR가 찍혔어. [줄 붙여넣기] 무슨 뜻인지, 사용자에게 영향이 있는지, 고쳐야 하는지 알려줘. 확실하지 않은 부분은 추측이라고 말해줘.
```

**AI에게** · 막히면 이렇게: 접속이 안 될 때.

```text
서버에 접속이 안 돼. 터미널에 이렇게 떠. [붙여넣기] 접속 허용 설정 문제인지 키 파일 문제인지 봐줘.
```

**AI에게** · 운영 데이터 확인.

```text
운영 데이터베이스에서 지난 7일 동안 가입한 사람 수와, 그중 회원을 한 명 이상 등록한 사람 수를 보고 싶어. 너는 운영 DB에 직접 접속하지 말고, 내가 DataGrip에서 실행할 SELECT 문만 써줘. 결과는 한 칸에 JSON 하나로 나오게.
```
