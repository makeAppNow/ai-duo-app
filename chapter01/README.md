# 1장. 생일 선물에서 자동으로 굴러가는 앱까지

책 본문에 나온 프롬프트, 터미널 명령, 예제 파일을 나온 순서대로 모았습니다. 앞뒤 설명은 책을 함께 봐 주세요.

## 이야기 중에

**AI에게**

```text
리액트 네이티브랑 엑스포로 앱을 만들려고 해. 첨부한 이미지처럼 아래에 탭 세 개(홈·일정·회원)를 두고 화면을 구성해줘.
```

## 기본: 클로드 코드, 개발 준비물, 깃허브 계정

**AI에게**

```text
[무엇]이 돼 있는지 확인해줘. 안 돼 있으면 내가 따라 할 수 있게 하나씩 알려줘.
```

**AI에게** · 맥을 사기 전이라면 claude.ai 웹 채팅이나 폰 앱에 물으면 된다.

```text
앱 개발용으로 맥을 사려고 해. 리액트 네이티브랑 엑스포로 아이폰·안드로이드 앱을 만들 거야. 맥미니랑 맥북 중에 뭐가 나은지, 어느 정도 사양이면 충분한지 알려줘.
```

## 기본 1-1. 클로드 코드 가입과 설치

**터미널** · 클로드 코드 공식 문서의 설치 페이지에 나온 한 줄을 복사해 터미널에 붙여넣고 엔터를 친다.

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**AI에게** · 막히면 이렇게: 설치 화면이 이 책과 다르게 생겼거나 에러가 떴을 때.

```text
터미널에 이런 화면이 떴어. [캡처] 뭘 해야 해? 내가 따라 할 수 있게 하나씩 알려줘.
```

## 기본 1-2. 개발 준비물 설치

**AI에게** · 방금 깐 클로드 코드에게 먼저 묻고 시작한다.

```text
내 맥에 앱 개발에 필요한 게 다 깔려 있는지 확인해줘. Xcode, 안드로이드 스튜디오, 깃. 빠진 게 있으면 내가 따라 할 수 있게 하나씩 알려줘.
```

## 기본 1-3. 깃허브 계정 만들기

**AI에게** · 2장에서 프로젝트를 만든 직후에 쓸 문장이다.

```text
깃허브에 비공개로 올려줘. 계정은 만들어뒀어. 내가 눌러야 하는 게 있으면 알려줘.
```
