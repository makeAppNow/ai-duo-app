## 자동화: 손으로 한 번, 그다음은 명령어와 테스트

**AI에게**

```text
방금 만든 기능을 상황별로 테스트하자. 확인할 상황 목록을 먼저 보여주고, 한 상황씩 데이터를 넣어줘. 데이터 이름에 어떤 상황인지 붙이고, 내가 확인하면 다음 상황으로.
```

**파일**

```
// 기준 시각: 2026년 7월 15일 오후 3시
it('만료일 당일은 시각이 지났어도 유효', () => {
  // 만료 시각이 오늘 오전 9시인 수강권
  const info = getMembershipDisplayInfo(
    membership({ endDateEpochMillis: at('2026-07-15T09:00:00') })
  );
  expect(info.text).toBe('오늘 만료 예정 (잔여 10회)');
});
```

**AI에게**

```text
수강권 만료 계산에 자동 테스트를 붙여줘. 만료일 당일은 유효, 다음 날부터 만료. 앞으로 코드를 고칠 때마다 이 테스트를 먼저 돌려.
```

**파일**

```
const reached = salesRevenue >= threshold;   // 판매 매출이 기준액 이상이면 인센티브
```

**AI에게**

```text
정산 계산 코드에 뮤테이션 테스트를 돌려줘. 테스트가 못 잡은 버그 중에서 경계값(이상과 초과, 0, 마지막 날)이나 조건 분기에 해당하는 것만 골라서 보여줘. 테스트를 보강할 때 정답은 지금 코드가 내는 값을 옮기지 말고 내가 정한 규칙에서 가져와. 규칙이 헷갈리면 나한테 먼저 물어봐.
```

**파일**

```
- launchApp
- tapOn: ".*회원"
- assertVisible: ".*이름.*검색.*"
- tapOn: ".*설정"
```

**AI에게**

```text
엑스포 SDK를 다음 버전으로 올려줘. 바뀐 점을 먼저 정리해서 보여주고, 올린 뒤에는 타입 검사·단위 테스트·화면 자동 테스트를 전부 돌려서 깨진 데를 알려줘.
```

**파일**

