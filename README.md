# AI와 둘이서 앱 하나: 예제 모음

『AI와 둘이서 앱 하나』(김희중 지음, 루비페이퍼)에 나오는 프롬프트, 터미널 명령, 예제 파일을 장별로 모았습니다.

## 쓰는 법

- 장 폴더의 README를 열면 책에 나온 순서대로 절 제목과 함께 정리돼 있습니다.
- **AI에게**는 클로드 코드 대화창에 그대로 붙여 넣는 문장, **터미널**은 터미널에 치는 명령, **파일**은 파일 내용 예시입니다.
- `[대괄호]` 안은 자기 상황으로 바꿔 넣습니다.
- 설치 명령과 서비스 화면은 바뀔 수 있습니다. 여기 적힌 명령이 안 되면 공식 문서를 먼저 확인하고, 막히면 화면을 캡처해 AI에게 보여 주세요.
